## B-1. 日次の実行を「火〜土」に変更してよいか

**当初のご指示（毎日 07:00 JST）からの変更提案です。**

検証の結果、**日曜と月曜の実行は米国市場の取引セッションを 1 つも含みません**（[09 §2-1](09-periodic-reports.md)）。07:00 JST = 17:00 ET（前日）という時刻設計上、金曜の引けは土曜朝の窓に入り、日曜・月曜の窓からは外れます。

| | 火〜土（推奨） | 毎日 |
|---|---|---|
| 日次の回数 | 22 回/月 | 30 回/月 |
| 空振り回 | なし | **週 2 回** |
| Bedrock 月額 | 約 $6.0 | 約 $7.8 |
| 週末ニュース | **週次レポート（月曜朝）が拾う** | 日次が拾う |

**推奨: 火〜土。** 空く月曜 07:00 JST の枠に週次レポートを充てます。米国市場の月曜寄り付きは 23:30 JST なので、月曜朝に前週の振り返りと今週の見通しを読める理想的なタイミングです。

**Phase 1 には影響しません**（ローカル CLI は日付を引数で指定するため）。Phase 2 の Scheduler 定義時までに決まっていれば十分です。

# F. 独自ドメイン（移行時の候補）

当面は **Amplify** のデフォルトドメイン（`main.<appId>.amplifyapp.com`）で運用します（A-52）。移行は代替ドメイン名 + ACM 証明書の追加のみで手戻りがありません。

## TLD の候補

| TLD | 年額目安 **[推定]** | 特徴 |
|---|---|---|
| `.com` | $10〜15 | 最も一般的 |
| **`.dev`** | $12〜15 | **HSTS プリロード済み** — ブラウザが HTTPS を強制 |
| **`.app`** | $12〜18 | 同じく **HSTS プリロード済み** |
| `.io` | $30〜60 | 技術系で人気だが高価 |
| `.jp` | ¥2,000〜4,000 | 日本向け |

セキュリティ重視の方針（A-6）に沿うなら **`.dev` / `.app`** を推奨。この 2 つは HSTS プリロードリストに **TLD 単位**で登録されており、ブラウザが HTTP アクセスを一切許可しません。

## ドメイン名の候補 **[要確認: 空き状況は未確認]**

| パターン | 例 |
|---|---|
| 指数名 + 用途 | `spx-brief.dev` / `sp500-daily.dev` / `spx-digest.app` |
| 分析の切り口 | `market-lens.dev` / `macro-brief.app` |
| 時間帯を示す | `morning-spx.dev` / `before-open.dev` |
| 日本語読み | `asaban.dev`（朝番）/ `souba-ai.dev`（相場AI） |

## レジストラ

| | Route 53 で一本化（推奨） | Cloudflare Registrar |
|---|---|---|
| 月額 | +$0.50（ホストゾーン） | $0 |
| ドメイン代 | 標準価格 | **原価（最安）** |
| Terraform 管理 | AWS プロバイダのみで完結 | Cloudflare プロバイダ + トークン管理が増える |

**推奨: Route 53。** 年額 $6 の差より、**Terraform の管理対象と認証情報を AWS 1 系統に閉じられる**ことを優先します。Cloudflare を使うと「秘密情報は Secrets Manager 1 箇所」という構成（[06](06-cicd-and-environments.md)）が崩れます。

# G. Phase 1 実装で判明したこと（2026-11-23）

実装と実データでの動作確認により、設計時には見えていなかった事項が判明しました。
いずれも対処済みです。

## G-1. ⚠️ 非ストリーミングでは `max_tokens` が 21,333 までに制限される

SDK は非ストリーミング時に `max_tokens` から想定所要時間を計算し、10 分を超える
値を **`ValueError` で拒否**します。実測した上限は **21,333**。

```
ValueError: Streaming is required for operations that may take longer than 10 minutes.
```

拡張スキーマ（17 フィールド × 5 件）+ 日本語レポート + 思考トークンで出力は
15K 前後になりうるため、**ストリーミングを既定**とし `max_tokens=32000` にしました。

## G-2. ⚠️ 市況の基準日が 1 営業日ずれていた

**07:00 JST = 前日 17:00 ET** なので、レポート日 D の朝に完了している最新の米国
セッションは **D-1** です。当初の実装は D をそのまま `asof` に渡しており、
**まだ取引が終わっていない日の終値を拾おうとしていました**。

`market_asof_for(report_date) = report_date - 1日` に修正。実データで
「JST レポート日 → 前日の ET セッション」の対応を確認済みです。

## G-3. ⚠️ 為替・商品は 24 時間取引されるため系列の日付が揃わない

実取得すると、株式は金曜終値・為替と商品は日曜の値を返しました。このまま
寄与度分解すると**異なる期間を比較**することになります。

`^GSPC` の最新営業日を基準日とし、**全系列をその日以前の最新行に揃える**よう
修正。修正後、理論値 -3.29% と `2559.T` 実測 -3.24% がほぼ一致し、手法の妥当性も
裏付けられました。

## G-4. FT の総合フィードが選抜を占有した

実データで選抜 15 件のうち **8 件が FT** になり、S&P500 と無関係なコラム・社説
（「Progressives are not radical enough on economics」等）が混入しました。
FT の `rss/home` は総合フィードで、セクション別フィード（`ft.com/markets` 等）は
**空（1件のみ）**で使えません。

**媒体あたりの選抜上限（`max_per_feed = 4`）** を導入。供給が少ない日に件数が
落ちないよう、上限超過分はラウンドロビンで埋めます（rank 順に詰めると偏りが戻るため）。
導入後、選抜は 6 媒体に分散しました。

## G-5. 言い換え記事はクラスタリングされない（既知の限界）

実データで 81 件 → 79 クラスタ。完全一致と微差（sim 0.92）は検知できましたが、
以下は**同一トピックなのに別クラスタ**になりました。

```
「How Asian countries are looking to prop up markets as AI downturn sinks stocks」(CNBC)
「Asian regulators rush to support sagging markets as AI trade falters」(FT)
```

語彙ベースの類似度の原理的な限界です。対処としては Embedding による意味的な
重複排除（[10](10-schema-capabilities.md) Tier D3）がありますが、**記事を全件保存
しているため後から生成できます**。当面は媒体上限（G-4）で多様性を担保し、
最終的な 5 件の選択は AI に委ねる設計で許容します。

## G-6. X 投稿のプレフィックスは想定より短かった

[12](12-global-index.md) で「約 32 字」と見積もったプレフィックスは、実測で
**重み 43（全角 21.5 文字相当）** でした。文字数ではなく X の重み付け
（全角 2 / 半角 1）で数えると、本文に **全角 118 文字**使えます。
当初懸念した窮屈さは発生しません。
