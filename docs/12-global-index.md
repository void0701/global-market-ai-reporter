# 12. オルカン（全世界株式）対応

最終更新: 2026-11-23

S&P500 に加えて **オルカン（全世界株式）の観点**をレポートに含める。本ドキュメントはその設計。

---

# 1. 「オルカン」をどのデータで表すか

「オルカン」は通常 **eMAXIS Slim 全世界株式（オール・カントリー）** を指し、**MSCI ACWI 指数**に連動する円建ての投資信託です。

## 1-1. 投資信託そのものは取得できない

```
0331418A.T （eMAXIS Slim 全世界株式の銘柄コード）  → ❌ 取得不可
```

日本の公募投資信託の基準価額は Yahoo Finance の chart API では取得できません **[確認済]**。

## 1-2. 採用する 3 系列

実機検証（2026-11-23）で取得できた代替手段を組み合わせます。

| # | 系列 | 通貨 | 役割 |
|---|---|---|---|
| **① `ACWI`** | USD | **iShares MSCI ACWI ETF。** オルカンと同じ指数に連動。ドル建ての純粋な株価変動 |
| **② `USDJPY=X`** | — | **為替。** 円建てリターンを決めるもう一方の要素 |
| **③ `2559.T`** | **JPY** | **MAXIS 全世界株式（MSCI ACWI）ETF。東証上場・円建て。** 実測の円建て値 |

```
取得確認（2026-11-20 終値）
  ACWI      142.59 USD
  USDJPY=X  159.707
  2559.T      2,748 JPY   ← 円建てで直接取れる
```

**③ `2559.T` が存在することが大きい。** 東証上場の ACWI 連動 ETF なので、オルカンに最も近い**実測の円建て値**が取れます。理論計算に頼らずに済みます。

## 1-3. 円建てリターンの分解

オルカン投資家にとって本質的な分解です。

```
円建て変化率 ≈ ドル建て株価の変化率 + 為替（円安方向）の変化率
```

この分解をレポートに明示します。たとえば:

> 「ACWI は **-2.0%** だが、円が **+1.2% 安**（159.71 → 161.6）となったため、**円建てでは -0.8%** にとどまった」

**ドル建てで下がっているのに円建てでは上がる（またはその逆）という状況が頻繁に起こるため、この分解がないとオルカン保有者には判断材料になりません。**

## 1-4. ⚠️ `2559.T` は 1 セッション遅れる

**時刻設計上の重要な注意点です。**

```
07:00 JST に実行した時点での「最新終値」

  ACWI      前日の 16:00 ET （= 当日 06:00 JST）  ← 最新の米国セッションを反映 ✅
  USDJPY=X  ほぼリアルタイム                       ✅
  2559.T    前営業日の 15:30 JST                  ← 1セッション遅れ ⚠️
```

東証は 15:30 JST に引けるため、07:00 JST の時点で `2559.T` の最新終値は**前営業日**のものです。その値は「さらに 1 つ前の米国セッション」を反映しています。

### 対応

| 用途 | 使う値 |
|---|---|
| **レポートに載せる円建て変化率** | **`ACWI × USDJPY` の理論値**（最新の米国セッションを反映） |
| **検証・乖離の監視** | `2559.T` の実測値（1 セッション遅れを明記して併記） |

理論値と実測値がともに保存されるため、**後から「理論値は実際の ETF をどの程度再現できていたか」を検証できます**（[11](11-data-retention.md) の方針に沿う）。

> なお実際の eMAXIS Slim は、約定日ベースで基準価額が決まるため `2559.T` ともさらにズレます。**本システムは「オルカンの正確な基準価額」を再現するものではなく、「全世界株式の円建ての動き」を把握するもの**と位置づけます。

# 2. 分析観点としての違い

S&P500 とオルカンでは、同じニュースでも影響が異なります。この差を構造化します。

## 2-1. MSCI ACWI の地域構成 **[推定: 概数]**

| 地域 | 構成比の目安 |
|---|---|
| 米国 | 約 60% |
| 欧州（先進） | 約 12% |
| 日本 | 約 5% |
| その他先進国 | 約 13% |
| 新興国 | 約 10% |

**米国が過半を占めるため、S&P500 とオルカンは強く連動します。** したがって「まったく別の分析」ではなく、**差分が出るケースを捉える**のが設計目標です。

## 2-2. 差分が出る 3 つのケース

| # | ケース | 例 | S&P500 | 円建てオルカン |
|---|---|---|---|---|
| **1** | **米国固有の材料** | 米国の独禁法規制強化、米国の雇用統計 | 大きく反応 | **影響が希釈される（約60%）** |
| **2** | **非米国の材料** | 中国の景気刺激策、ECB の政策変更、新興国通貨危機 | 限定的 | **相対的に大きく効く** |
| **3** | **為替要因** | 日銀の利上げ、円キャリー取引の巻き戻し | **ほぼ無関係** | **直接効く（円高はマイナス）** |

**ケース 3 が最も重要です。** 「日銀が利上げ」というニュースは S&P500 の分析では脇役ですが、**円建てオルカン保有者には直撃します**。現在のスキーマではこの観点がまったく拾えません。

# 3. スキーマへの反映

## 3-1. `news_analysis[]` に追加する 3 フィールド

```python
RegionFocus = Literal["us", "europe", "japan", "em", "china", "global"]
Scope       = Literal["us_specific", "global"]
FxImpact    = Literal["yen_weaker", "yen_stronger", "neutral"]

class NewsAnalysis(BaseModel):
    # ... 既存 + [11](11-data-retention.md) の追加分 ...
    region_focus: RegionFocus    # どの地域の材料か
    scope: Scope                 # 米国固有か全世界共通か
    fx_impact: FxImpact          # 円相場への影響（円安=オルカン円建てにプラス）
```

| フィールド | これで集計できるようになること |
|---|---|
| `region_focus` | 「今月の材料は米国 11 件、中国 3 件、欧州 2 件」。地域ETF の実績と突き合わせ可能 |
| `scope` | **「S&P500 固有の下落圧力か、全世界共通か」** — ケース 1 の識別 |
| `fx_impact` | **「円高要因が 5 件。オルカン円建てには逆風」** — ケース 3 の識別 |

## 3-2. トップレベルに追加

```python
class DailyAnalysis(BaseModel):
    sentiment_score: int                   # S&P500 向け（既存）
    sentiment_summary: str
    acwi_sentiment_score: int              # ★円建て全世界株式向け（為替込み）
    acwi_sentiment_summary: str            # ★
    fx_outlook: str                        # ★為替の見通し
    # ... 以下既存 ...
```

**センチメントスコアを 2 本持つ理由:** ケース 1〜3 により両者は乖離します。1 本のスコアに押し込めると、どちらの投資家にも中途半端になります。

`acwi_sentiment_score` は **為替影響を織り込んだ総合評価**とします（円建てのリターンに対する見通し）。たとえば「世界株は弱いが円安が進行」なら、S&P500 が -3 でもオルカンは -1 になりえます。

# 4. レポートへの反映

**別レポートにはしません。** ニュースは共通であり、2 本に分けると重複が多く、X 投稿も倍になります。**1 本の統合レポート**の中で両方の観点を示します。

## 4-1. 日次レポートの構成

```
■ サマリ
   S&P500 センチメント       -3  「金利上昇とハイテク売りが継続」
   オルカン（円建て）         -1  「世界株安だが円安が下支え」
   
■ 市況
   S&P500      6,910.39   -3.70%
   ACWI (USD)    142.59   -2.10%
   USD/JPY      159.707   +0.80%（円安）
   ─────────────────────────────────
   円建て全世界株（理論値）   -1.32%   ← ACWI × USDJPY
   2559.T（実測・1営業日前）  2,748    -1.05%
   ─────────────────────────────────
   VIX           35.89   10年債 4.912%（+12bp）

■ 重要ニュース（最大5件）
   各ニュースに 地域 / 米国固有か / 円相場への影響 を付記

■ オルカン保有者向けの観点      ← 新設セクション
   為替の見通しと、米国固有要因の希釈について

■ 監視リスト
```

## 4-2. 期間レポート（[09](09-periodic-reports.md)）への追加集計

| 集計 | 出力例 |
|---|---|
| ACWI の期間騰落率（ドル建て） | 「11月の ACWI は -5.2%」 |
| **円建ての期間騰落率** | **「円安 +2.1% が効き、円建てでは -3.2% にとどまった」** |
| **リターンの寄与度分解** | **「下落 -3.2% のうち、株価要因 -5.2%、為替要因 +2.1%」** |
| S&P500 との乖離 | 「S&P500 -8.5% に対し ACWI -5.2%。米国固有要因が主導」 |
| `scope` の分布 | 「米国固有の材料が 16 件中 11 件」 |
| `fx_impact` の分布 | 「円高要因 5 件 / 円安要因 2 件」 |
| `region_focus` の分布 | 「米国 11・中国 3・欧州 2」 |
| 地域ETF の実績比較 | 「EWJ +1.2%、VGK -3.1%、EEM -6.8%」 |
| **オルカン向けの的中率** | `acwi_sentiment_score` と円建て実績の方向一致率 |

**リターンの寄与度分解が期間レポートで最も価値が高い集計です。** 「今月オルカンが下がったのは世界的な株安か、それとも円高か」が月次で明確に分かります。

# 5. X 投稿への影響

**[05](05-decisions.md) A-21 の投稿プレフィックスを変更します。**

```
変更前: 【2026/11/21 米国市場AI解析 S&P500 -3.70%】
変更後: 【2026/11/21 米国市場AI解析 S&P500 -3.70% / 全世界株(円) -1.32%】
```

> ⚠️ **全角 140 文字の制約が厳しくなります。** プレフィックスが約 24 字 → 約 42 字に伸び、本文に使える文字数が 18 字減ります。

[04](04-phase1-plan.md) のとおり **プレフィックスはコード側で生成し、本文に許される残り文字数を正確に算出する**設計なので、実装上の対応は閾値の変更だけです。ただし本文が窮屈になるため、以下のいずれかを選ぶ必要があります。

| 案 | 内容 |
|---|---|
| **A（推奨）** | **プレフィックスを短縮**: `【11/21 米株 -3.70% / 全世界株(円) -1.32%】`（約 32 字） |
| B | 騰落率を S&P500 のみに戻し、オルカンは本文で言及 |
| C | 本文を短くする（情報量が落ちる） |

**推奨は A。** 日付を `MM/DD` に、「米国市場AI解析」を「米株」に短縮します。Error 187（重複投稿）回避の要件は、日付と 2 つの騰落率が毎日変わるため引き続き満たされます。

→ **この短縮案の可否をご確認ください**（[00](00-open-items.md) に記録）。

## プロンプト設計上の注意

**MSCI ACWI の地域構成比をプロンプトに明記します。** モデルに「オルカンは米国が約 60%」という前提を与えないと、米国固有のニュースをオルカンにも同程度の影響として評価してしまう可能性があります。構成比は年に 1 回程度見直せば十分です **[要確認: 正確な最新構成比]**。

また **「円安はオルカン円建てにプラス」という方向性を明示**します。直感に反する投資家もいる論点であり、モデルが混乱しうるため明記が必要です。
